## Repository settings

Recommended public settings:

- default branch: `main`
- Issues: enabled
- merge requests / pull requests: enabled
- private vulnerability reporting: enabled when available
- license detection: Apache-2.0 from the root `LICENSE`
- wiki: optional; normal documentation lives in `docs/`
- discussions: optional; support currently uses issue forms

## Public links

Plugin/project metadata should point to:

~~~text
https://github.com/Yuries-Public-Stuff/Kanvas
~~~

The Gradle plugin source URL should use:

~~~text
https://github.com/Yuries-Public-Stuff/Kanvas.git
~~~

Do not expose private development repository URLs in published plugin metadata, documentation, packaged output, or examples.
